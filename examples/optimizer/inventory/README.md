# 配送網の過去状態と距離別在庫

入力の先頭は拠点数 V と操作数 N（1 ≤ V ≤ 12,000、1 ≤ N ≤ 50,000）。続く V−1 行は `u v distance` で、拠点1〜Vを結ぶ無向木を表す。辺の距離は1〜10^9。2拠点間の距離は唯一の経路の辺の距離の和。

品目は1〜8の整数で、全拠点・全品目の在庫数は最初は0。続くN行の操作を入力順に扱う。

| 操作 | 意味 |
| --- | --- |
| `U site item quantity` | 拠点siteの品目itemの在庫数をquantity（0〜10^9）に置き換える。 |
| `S name` | 全拠点の現在の在庫を名前付きで保存する。同じ名前は上書きする。 |
| `R name` | 指定の保存状態を現在の状態にする。未登録の名前は無視する。 |
| `Q site item low high` | 拠点siteからの距離がlow以上high以下で、品目itemが1個以上ある拠点の数と、その品目の在庫合計を出力する。 |

距離条件は 0 ≤ low ≤ high ≤ 10^14。照会元も距離0の拠点として数えられる。保存名は1〜16文字のASCII英数字。名前の対応は入力順に更新され、復元で巻き戻らない。保存済みの状態は復元後に更新しても変わらない。出力は照会順に `拠点数 在庫合計` を1行ずつ。該当拠点がなければ `0 0`。入力をすべて読んでから処理してよい。未使用の50,000操作を1実行3秒以内で処理する。
