# 訂正可能な取引台帳

標準入力の先頭に操作数 N（1〜200,000）。続くN行を受信順に適用する。取引の時刻と行の順番は独立している。時刻は0〜10^9の整数、取引IDと利用者IDは1〜16文字のASCII英数字で、大文字と小文字を区別する。額と増減額はそれぞれ −10^9〜10^9 の整数。増減後の額も整数として正確に扱う。

| 操作 | 意味 |
| --- | --- |
| `P id user time amount` | 登録する。同じ取引IDが存在すれば、以前の利用者・時刻・額を置き換える。 |
| `M id user time` | 現在の額を保って、利用者と時刻を移す。存在しないIDは無視する。 |
| `A id delta` | 現在の額に delta を足す。存在しないIDは無視する。 |
| `D id` | 削除する。存在しないIDは無視する。削除後の再登録は新しい取引として扱う。 |
| `Q user end width` | 現在登録されていて、同じ利用者かつ `end - width < time <= end` を満たす取引を集計する。endとwidthは0〜10^9の整数。 |

Qごとに `件数 合計 最新取引ID` の1行を出力する。最新は時刻が最大の取引。同時刻ではASCII辞書順で最大のIDを選ぶ。額が0や負でも件数や最新IDの判定に含める。該当がなければ `0 0 -`。Q以外の操作に対する出力はない。最終状態だけを使って過去のQを再計算してはいけない。入力全体を先に読み、索引の準備に使ってよい。

未使用の20万操作で、起動・入出力を含めて1実行3秒以内。入力は一利用者への集中、利用者への分散、同時刻と訂正の集中を含む。
