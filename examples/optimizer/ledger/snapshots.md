# 分岐できる取引台帳

[訂正可能な取引台帳](README.md) の入出力、取引操作、200,000操作を3秒以内で処理する要件に、次の2操作を加える。通常の `P`・`M`・`A`・`D` は現行の取引状態に作用し、`Q` は現行状態を集計する。

| 操作 | 意味 |
| --- | --- |
| `S name` | 現行の取引状態に名前を付けて保存する。既存の名前なら上書きする。 |
| `R name` | その名前で最後に保存した取引状態を現行にする。名前が未登録なら何もしない。 |

nameは取引IDと同じ文字制約で、取引IDとは独立した名前空間。保存後に取引を編集しても保存した状態は変わらない。復元してから変更した状態は、同じ保存点から分岐した別の状態になる。復元しても保存名の一覧や他の保存点は変わらない。すでに出力した照会結果も変わらない。S・Rに出力はない。入力全体を先に読み、索引の準備に使ってよい。
