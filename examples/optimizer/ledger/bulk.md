# 分岐と一括訂正のある取引台帳

先に示した登録・移動・増減・削除・照会・保存・復元に、次の操作を加える。この課題の入力上限は100,000操作。未使用の100,000操作を起動・入出力込みで1実行3秒以内に処理する。入力を先に読み、索引の準備に使ってよい。

`B user end width delta` は、その操作の時点で指定利用者に属し、`end - width < time <= end` を満たす取引すべての額に delta を加える。対象となる取引がない場合は何もしない。出力はない。

一括訂正後の額を、その後の移動・増減・照会で使用する。削除した取引や後から登録する取引に、以前の一括訂正を適用しない。同じ座標に再登録した場合も、登録時の額を使う。保存した枝には保存時点の訂正が残り、別の枝で行った訂正は混ざらない。時刻、窓、ID、整数の範囲は通常の操作と同じ。
