# 版を持つ区間更新と集計

先頭行は配列の長さ N と操作数 Q。1 ≤ N ≤ 10^9、1 ≤ Q ≤ 36,000。配列 a は添字1〜Nで、初期値はすべて0。計算は 1,000,000,007 を法とする。

| 操作 | 意味 |
| --- | --- |
| `U l r m b` | l ≤ i ≤ r の各 a[i] を m × a[i] + b に置き換える。m、b は 0〜1,000,000,006。 |
| `Q l r` | 閉区間 l〜r の Σa[i]、Σa[i]²、Σi×a[i] をこの順で1行出力する。 |
| `S name` | 現在の配列を名前付きで保存する。同名は上書きする。 |
| `R name` | 名前の配列を現在の配列にする。未登録の名前は無視する。 |

区間には常に 1 ≤ l ≤ r ≤ N が成立する。保存名は1〜16文字の英数字。復元後の更新で過去に保存した値は変わらない。名前の対応は入力順に更新され、復元で巻き戻らない。出力は照会が現れた順に、非負の剰余を空白で区切る。入力全体を先に読んでもよい。未使用の36,000操作を1実行3秒以内で処理する。
