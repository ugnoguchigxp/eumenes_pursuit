# 変更されるネットワークの照会

先頭行は頂点数 V と操作数 N。1 ≤ V ≤ 60,000、1 ≤ N ≤ 60,000。頂点は1からVで、重みは最初はすべて0。操作は入力順に適用する。

| 操作 | 意味 |
| --- | --- |
| `P id u v p` | 無向リンクを登録する。p は0または1で、両端のラベルのXORに対する制約。既存の同じIDのリンクは置き換える。 |
| `D id` | リンクを削除する。登録されていないIDは無視する。 |
| `A u delta` | 頂点uの重みに符号付き整数deltaを加える。リンクの追加・削除とは独立して保持する。 |
| `Q u v` | 現在のリンク集合について、下記の結果を1行出力する。 |

IDは1〜16文字のASCII英数字。平行リンクと自己リンクを許す。deltaは−10^9〜10^9で、集計は正確な整数で行う。出力は `関係 uの連結成分の頂点数 uの連結成分の重み合計`。uとvが別成分なら関係は `unknown`。同じ成分に矛盾する制約が1つでもあれば、uとvが同じ頂点でも `conflict`。そのほか、uとvのXORが0なら `same`、1なら `different`。

未使用の60,000操作を1実行3秒以内で処理する。入力全体を先に読んで処理してよい。リンクの一部だけを保持する、入力の最終状態で過去の照会に答える、仕様や検査を変更するといった方法では合格しない。
