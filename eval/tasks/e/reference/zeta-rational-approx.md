# ζ(3) の有理近似（研究の概要）
Apéry（1978）は ζ(3) の無理数性を、整数係数の漸化式を満たす二つの数列による有理近似で示した。
Beukers（1979）は二重積分 ∫₀¹∫₀¹ −ln(xy)/(1−xy) · P_n(x)P_n(y) dx dy（P_n はルジャンドル型多項式 (1/n!) dⁿ/dxⁿ [xⁿ(1−x)ⁿ]）を用い、これが (a_n + b_n ζ(3))/d_n³ の形（d_n = lcm(1,…,n)）になることを示した。
素数定理より d_n = e^{n(1+o(1))}。無理数性の議論には「整数性」「0 でないこと」「十分速く 0 に収束すること」の三つが要る。
