# 調和数と Euler 和
H_n = Σ_{k≤n} 1/k。母関数: Σ H_n x^n = −ln(1−x)/(1−x)。部分和の交換: Σ_n Σ_{k≤n} a_k b_n = Σ_k a_k Σ_{n≥k} b_n。
既知の値: ζ(2) = π²/6、ζ(4) = π⁴/90、Σ_{n≥1} H_n/n² = 2ζ(3)、Σ_{n≥1} (−1)^{n+1}/n = ln 2、Σ_{n≥1} (−1)^{n+1}/n² = π²/12。
二次の Euler 和は、二重級数・積分表示（∫₀¹ x^{n−1} ln(1−x) dx = −H_n/n）や ζ(4) との関係で整理する。
