# 正多角形による円周率の評価
半径 r の円に内接する正 n 角形の周長は 2nr·sin(π/n)、外接する正 n 角形の周長は 2nr·tan(π/n)。
内接多角形の周長 < 円周 < 外接多角形の周長（凸性による）。
主な値: sin(π/6) = 1/2、sin(π/4) = √2/2、sin(π/12) = (√6−√2)/4、cos(π/12) = (√6+√2)/4、tan(π/12) = 2−√3、sin(π/8) = √(2−√2)/2、tan(π/8) = √2−1。
半角公式: sin²(θ/2) = (1−cos θ)/2、tan(θ/2) = sin θ/(1+cos θ)。n を倍にすると評価は約 4 倍精密になる。
