# Beukers の積分の補題
d_n = lcm(1, 2, …, n)。
補題1（二重積分の値）: 整数 r, s ≥ 0 について ∫₀¹∫₀¹ −ln(xy)/(1−xy) · x^r y^s dx dy は、r > s のとき分母が d_r³ を割る有理数、r = s のとき 2(ζ(3) − Σ_{k=1}^{r} 1/k³)。
補題2: P_n(x) = (1/n!) dⁿ/dxⁿ [xⁿ(1−x)ⁿ] は整数係数の n 次多項式。補題1と合わせ、I_n = ∫∫ −ln(xy)/(1−xy) P_n(x)P_n(y) dx dy は (A_n + B_n ζ(3))/d_n³（A_n, B_n ∈ ℤ）の形。
補題3（三重積分と評価）: −ln(xy)/(1−xy) = ∫₀¹ dw / (1 − (1−xy)w)。n 回の部分積分で I_n を被積分関数 (x(1−x)y(1−y)w(1−w)/(1−(1−xy)w))ⁿ / (1−(1−xy)w) の三重積分に書き直せる。その最大値は (√2 − 1)⁴ で、0 < I_n ≤ 2(√2−1)^{4n} ζ(3)。
補題4: 素数定理（または初等的な評価）から、十分大きな n で d_n < 3ⁿ。
組み立て: 0 < |A_n + B_n ζ(3)| = d_n³ I_n < 27ⁿ (√2−1)^{4n} · 2ζ(3) → 0（27(√2−1)⁴ < 1）。
