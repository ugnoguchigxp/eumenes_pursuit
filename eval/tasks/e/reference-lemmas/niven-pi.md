# Niven の議論（π の無理数性）の補題
f(x) = xⁿ(a − bx)ⁿ / n!（π = a/b と仮定）とおく。
補題1: 0 ≤ j で f^{(j)}(0) と f^{(j)}(π) は整数（f は整数係数多項式を n! で割ったもので、j < n では 0、j ≥ n では階乗が打ち消す。f(π − x) = f(x) から π 側も同じ）。
補題2: F(x) = f(x) − f''(x) + f^{(4)}(x) − … とすると (F′(x) sin x − F(x) cos x)′ = f(x) sin x。よって ∫₀^π f(x) sin x dx = F(π) + F(0) は整数。
補題3: 0 < x < π で 0 < f(x) sin x ≤ πⁿ aⁿ / n!。n を大きくとると積分は 0 と 1 の間。矛盾。
π² に適用するときは、仮定する量・補助関数・区間（[0,1] と sin πx など）を合わせて作り直す必要がある。
