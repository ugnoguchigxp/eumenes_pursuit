# roomstats

会議室の予約記録から、部屋ごとの利用時間と利用率を集計する小さなツール。

```
python3 -m roomstats < bookings.csv
```

## 入力

CSV（1 行目は見出し `room,start,end`）。各行が 1 件の予約。

- `room`: 部屋名（英数字）
- `start`, `end`: `HH:MM`（00:00〜24:00）。`start < end`。同じ部屋の予約が重なっていることがある（二重予約・延長の記録など）。

## 出力

予約が 1 件以上ある部屋ごとに 1 行、部屋名の昇順で、タブ区切り:

```
<room>\t<busy>\t<pct>
```

- `busy`: 開館時間（08:00〜20:00、720 分）のうち、その部屋に少なくとも 1 件の予約がかかっている分数。重なりは二重に数えない。開館時間外の部分は数えない。
- `pct`: `busy / 720 * 100` を小数第 1 位に四捨五入（0.05 は切り上げ）し、小数第 1 位まで書く（例: `50.0`, `1.3`）。
