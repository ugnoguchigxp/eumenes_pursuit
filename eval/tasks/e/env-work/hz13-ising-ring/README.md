# 横磁場イジング環の有限サイズの厳密な値

## 定義

L 個のスピン 1/2 が環状に並ぶ。ハミルトニアンは

```
H = −J Σ_{i=1}^{L} σx_i σx_{i+1} − h Σ_{i=1}^{L} σz_i ,   σx_{L+1} = σx_1
```

σx, σz はパウリ行列。J と h は 0 でない実数で、符号はどちらもありうる。H は 2^L 次元の行列であり、求める量はすべて**有限の L における厳密な値**である（熱力学極限の値ではない）。

固有値を重複を含めて小さい順に E_0 ≤ E_1 ≤ … と書く。

| 問い | 求める量 |
| --- | --- |
| `E0 L J h` | 基底エネルギー E_0 |
| `GAP L J h` | E_1 − E_0。基底状態が厳密に縮退していれば 0 |
| `F L J h beta` | 自由エネルギー F = −(1/β) ln Tr exp(−βH) |

## 入出力

`python3 solve.py` を実行する。標準入力の1行目は問いの数 Q。続く Q 行に上の形式の問いが1行ずつある。J・h・beta は10進表記。問いごとに答えを1行ずつ標準出力に書く。

答えは**有効数字8桁**の指数表記で書く。C の `printf("%.7e")` と同じ書式とし、最後の桁は四捨五入する（例: `-1.5322595e+01`、`2.5412514e-04`）。厳密に 0 の値は `0.0000000e+00` と書く。どの問いも、真の値が丸めの境界から十分離れるように選んである。

例（`samples/t1.in` の形式）: `GAP 8 1.20 -0.75`

## 入力の範囲

隠された検査は6段階あり、各段階に2ファイル、1ファイルに最大12問ある。ファイル内の全問が一致したときに、そのファイルを通過とする。

| 段階 | 問い | 範囲 |
| --- | --- | --- |
| 1 | E0・GAP・F | 3 ≤ L ≤ 10。J と h は正負どちらも |
| 2 | E0 | 50 ≤ L ≤ 400。J > 0、h > 0 |
| 3 | F、E0 | F は 12 ≤ L ≤ 60、J > 0、h > 0、1 ≤ β ≤ 20。E0 は L が奇数で J < 0、h > 0（L ≤ 199） |
| 4 | GAP | 6 ≤ L ≤ 400。\|h\| > \|J\|、\|h\| = \|J\|、J < 0 で L が奇数、\|h\| < \|J\| で L が小さい場合を含む。0 でない答えは 10^-4 以上 |
| 5 | GAP | 24 ≤ L ≤ 400、\|h\| < \|J\|。答えは 10^-80 より大きいが、非常に小さいことがある |
| 6 | GAP | 400 < L。J > 0、h > 0。h < J では L ≤ 10^9、h = J では L ≤ 10^15、h > J では L ≤ 20000 |

## 段階6の出力

段階6の答えは 10^-(10^9) 程度まで小さくなりうる。書式は同じで、指数は必要な桁数だけ書く（例: `4.2771722e-45757496`）。有効数字8桁が正しいことを求める。

## 制約

- 使えるのは Python 3 の標準ライブラリだけ（numpy などはない）。ネットワークはない。
- 1ファイルあたりの制限時間は 20 秒。
- `samples/` には段階1の入力と正しい出力がある。段階2以降の正解は与えられない。
