# 質問

## 数え方（すべての質問に共通）
- 出荷は shipment_id で一つと数える。同じ出荷に記録が複数あるときは、訂正を反映した最新の記録を使う。
- 最新の記録の status が cancelled の出荷は数えない（以下「有効な出荷」は cancelled でない出荷）。
- 日付・月・年は、すべて日本時間（JST, UTC+9）の出荷日時で数える。「2025年」は JST で 2025-01-01 00:00 から 2025-12-31 23:59 まで。
- 顧客は customer_codes.csv の新コード（CUS-NNNN-X）で同定する。旧コードで書かれた記録は、対応表で新コードに読み替える。
- 重量は kg。ポンドの値は 1 lb = 0.45359237 kg で換算する。

## 質問
- q1: 2025年7月〜9月の、顧客 CUS-9031-H の有効な出荷の料金（fee_yen）の合計（円、整数）。
- q2: 2025年の有効な出荷の総重量（kg）。各記録の値を換算して合計してから、小数第1位に四捨五入する。
- q3: 2025年1月〜6月と 2025年7月〜12月の両方に、有効な出荷が 1 件以上ある顧客の数（整数）。
- q4: 2025年10月〜12月で、有効な出荷の件数が最も多かった日（q4_date、YYYY-MM-DD）と、その件数（q4_count、整数）。
- q5: 2025年の有効な出荷の料金の合計が最も大きい顧客（新コード）。

## 答えの形
/work/answers.json に、次の形の JSON オブジェクトを一つ書く。

```json
{"q1": 0, "q2": "0.0", "q3": 0, "q4_date": "2025-01-01", "q4_count": 0, "q5": "CUS-0000-A"}
```

q2 は小数第1位までの文字列。
