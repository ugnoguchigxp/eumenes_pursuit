# 黒箱の再現（記号列の装置）

`probe` で問い合わせられる装置がある。装置は文字列を 1 つ受け取り、0 以上 96 以下の整数を 1 つ返す。同じ文字列にはいつも同じ値を返す（問い合わせの間で状態は持ち越さない）。

- 入力に使える文字: 英小文字 `a` `b` `c` `d` `e` と数字 `0`〜`9`。長さ 0〜24。
- それ以外の文字を含む入力や 25 文字以上の入力には `invalid` を返す。

装置と同じ値を返す `predict.py` を書くこと。

```
python3 predict.py < inputs.txt
```

- 入力: 1 行に 1 つずつ文字列（空行は長さ 0 の文字列）。
- 出力: 入力の各行について、装置が返す値を 1 行ずつ、入力の順に。

`predict.py` は装置に問い合わせずに動くこと（検査のときに装置はない）。問い合わせの回数には上限がある。
