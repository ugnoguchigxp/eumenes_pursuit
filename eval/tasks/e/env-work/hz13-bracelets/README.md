# 向きのある隣接条件つきブレスレットの数え上げ

## 定義

円周上に n 個の位置があり、時計回りに 0, 1, …, n−1 と番号を付ける。各位置を k 色（0 … k−1）のどれかで塗る。

- k×k の 0/1 行列 A が与えられる。塗り方 c が**適合**しているとは、すべての i について A[c_i][c_{(i+1) mod n}] = 1 が成り立つことをいう。A は対称とは限らない。条件は時計回りに読んだ隣接対に課される。
- 二つの塗り方は、回転または裏返し（二面体群 D_n の作用）で移り合うとき、同じ**ブレスレット**とみなす。
- 求めるのは、**適合した塗り方を少なくとも一つ含むブレスレットの個数**を M で割った余りである。

## 入出力

`python3 solve.py` を実行する。標準入力の1行目は問いの数 Q。続く Q 行はそれぞれ

```
n M k row_0 row_1 … row_{k−1}
```

で、row_i は A の第 i 行を k 文字の 0/1 で書いたもの。問いごとに答えを1行ずつ、10進整数（0 以上 M 未満）で標準出力に書く。

例（`samples/t1.in` の形式）: `5 1000000007 2 01 11`

## 入力の範囲

隠された検査は6段階あり、各段階に2ファイル、1ファイルに12問ある（段階6は6問）。ファイル内の全問が一致したときに、そのファイルを通過とする。

| 段階 | n | k | A | M |
| --- | --- | --- | --- | --- |
| 1 | 3 ≤ n ≤ 11 | 2〜3 | 対称・非対称の両方 | 1000000007 |
| 2 | 20 ≤ n ≤ 2000 | 2〜4 | 対称 | 998244353 |
| 3 | 20 ≤ n ≤ 2000 | 3〜4 | 非対称 | 998244353 |
| 4 | 3 ≤ n ≤ 10^18 | 2〜4 | 両方 | 1000000007（2n と互いに素） |
| 5 | 3 ≤ n ≤ 10^18 | 2〜4 | 非対称 | 2 ≤ M ≤ 10^12。合成数、偶数、n の約数、n と共通因数を持つ数を含む |
| 6 | 3 ≤ n ≤ 10^18 | 200〜1200 | 巡回行列（下の形式） | 2 ≤ M ≤ 10^12。素数、合成数、2 の冪 |

段階4・5の n は、大きな素数、二つの大きな素数の積、素数冪、小さな素因数だけの数を含む。n の約数の個数は 64 以下。

## 段階6の入力

段階6では k が大きいので、A を行ごとには与えない。問いは

```
n M k @ d_1 d_2 … d_c
```

の形で、`A[i][j] = 1` となるのは `(j − i) mod k` が d_1 … d_c のどれかに等しいときだけである（0 ≤ d < k、c は 2〜6）。n の約数の個数は 12 以下。定義と求める量は他の段階と同じ。

## 制約

- 使えるのは Python 3 の標準ライブラリだけ。ネットワークはない。
- 1ファイルあたりの制限時間は 20 秒。
- `samples/` には段階1の入力と正しい出力がある。段階2以降の正解は与えられない。
