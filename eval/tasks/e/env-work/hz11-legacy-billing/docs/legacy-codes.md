# 旧予約システムのプランコード

旧システムから移行したアカウントの plan_history には旧コードが残っている。カタログのコードに読み替えて使う。

| 旧コード | 読み替え |
| --- | --- |
| STD | starter-2025 |
| PRO | pro-2025 |
| BIZ | 2025-03-31 までの日は business-2024、2025-04-01 以降の日は business-2025 |

- どの日付で読み替えるか: 日割りの区間の基本料金はその区間の初日、含まれる単位数・超過料金の段と出力の plan は請求期間の最終日。
