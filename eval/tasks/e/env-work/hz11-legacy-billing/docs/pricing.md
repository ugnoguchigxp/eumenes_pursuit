# 料金

## 基本料金
- 請求期間ごとにプランの基本料金（base_yen）。
- 請求期間の途中でプランが変わったときは、プランごとの区間に分けて日割りする。
  - 区間の基本料金 = そのプランの基本料金 × 区間の日数 ÷ 30（1 か月を 30 日として計算する）。
  - 区間ごとに円未満を四捨五入してから合計する。
- 区間の日数は、区間の初日を含み、次の区間の初日を含まない。

## 超過料金
- 請求期間の利用単位の合計がプランの含まれる単位数（included_units）を超えた分が超過量。
- 単価はカタログの段（tiers）で決まる。各段は width 単位ぶん（width が null の段は残り全部）。
- 超過量が到達した段の単価を、超過量の全体に掛ける（数量制）。
- 含まれる単位数と段は、請求期間の最終日に有効なプランのものを使う。
