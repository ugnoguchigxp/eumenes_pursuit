# windowsum

取引記録から、各取引について「同じ利用者の直近 1 時間の取引額の合計」を求める。

```
python3 windowsum.py < events.txt
```

## 入力

1 行目に件数 N（1 ≤ N ≤ 200000）。続く N 行に `t user amount`（空白区切り）。

- `t`: 時刻（秒、0 ≤ t ≤ 10^9 の整数）。入力は時刻順とは限らない。同じ時刻の取引が複数あってもよい。
- `user`: 利用者 ID（英数字、1〜16 文字）
- `amount`: 金額（整数、-10^6 ≤ amount ≤ 10^6。返金は負）

## 出力

入力の順に N 行。i 行目は、i 番目の取引と同じ利用者の取引のうち、時刻 t' が `t - 3600 < t' <= t` を満たすもの（i 番目自身と、同時刻の取引を含む）の amount の合計。

## 性能

N = 200000 の入力を、1 回の実行あたり 3 秒以内に処理できること。

python3 -m unittest discover -s tests -t .
