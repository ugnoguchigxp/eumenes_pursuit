# 沈殿を含む水溶液の化学平衡

## 定義

水溶液の平衡組成を求める。系は**成分** 0 … NC−1 で書かれ、成分 0 は H⁺ である。水の活量は 1 とする。

- **溶存種** j は、成分から生成定数 K_j と整数の係数 ν_j で作られる: `a_j = K_j · Π_i a_i^{ν_ji}`（a は活量）。成分そのものも溶存種である。H⁺ の係数は負になりうる（OH⁻ は ν_H = −1、log K = −14）。
- **固相** p は、生成定数 Ks_p と整数の係数 μ_p を持つ。飽和指数を `SI_p = log10 Ks_p + Σ_i μ_pi · log10 a_i` とする。固相の量を n_p（溶液 1 L あたりの mol、n_p ≥ 0）とすると、平衡では各固相について「n_p > 0 かつ SI_p = 0」または「n_p = 0 かつ SI_p ≤ 0」が成り立つ。
- **物質収支**: 各成分 i について `T_i = Σ_j ν_ji · c_j + Σ_p μ_pi · n_p`。和は成分自身（係数 1）を含むすべての溶存種にわたる。c は濃度（mol/L）。T_0（H⁺ の総量）は負になりうる。
- **活量**: MODEL = 0 では a = c。MODEL = 1 では a = γ·c で、電荷 z の溶存種の γ は Davies 式 `log10 γ = −0.509 · z² · ( √I / (1 + √I) − 0.3 · I )` で与える。イオン強度は `I = ½ Σ z_j² c_j`（成分を含むすべての溶存種の和。固相は含めない）。溶存種の電荷は成分の電荷と係数から決まる（Σ_i ν_ji z_i）。

求めるのは、上のすべてを同時に満たす平衡である。

## 入出力

`python3 solve.py` を実行する。標準入力の最初の数は系の数 Q。各系は次の並びで与えられる（空白・改行区切り）。

```
NC NS NP MODEL
T_0 … T_{NC−1}                 成分の総量 (mol/L)
z_0 … z_{NC−1}                 成分の電荷
log10 K_j  ν_j0 … ν_j,NC−1      （NS 行。成分自身は含まれない）
log10 Ks_p μ_p0 … μ_p,NC−1      （NP 行）
```

系ごとに1行、次の NC + NP 個の値を空白区切りで書く。

1. 各成分の**自由濃度**の常用対数 log10 c_i（小数点以下5桁、`%.5f`）
2. 各固相の量 n_p（`%.5e`。存在しない固相は `0`）

例: `-11.42884 -2.67733 -16.15769 -4.85786 -7.04153 2.21912e-06 0`

どの系も、平衡が一意で、答えが丸めの境界や相の出現・消失の境界から十分離れるように選んである。

## 入力の範囲

隠された検査は6段階あり、各段階に2ファイル、1ファイルに8系ある（段階6は16系）。ファイル内の全系が一致したときに、そのファイルを通過とする。

| 段階 | 成分 NC | 溶存種 NS | 固相 NP | MODEL |
| --- | --- | --- | --- | --- |
| 1 | 2〜3 | 〜6 | 0 | 0 |
| 2 | 5〜7 | 〜20 | 0 | 0 |
| 3 | 4〜7 | 〜20 | 2〜6 | 0 |
| 4 | 3〜7 | 〜20 | 0〜6 | 1 |
| 5 | 7〜10 | 〜35 | 10〜25 | 0 と 1 |
| 6 | 12〜16 | 〜90 | 30〜60 | 0 と 1 |

総量は 10^-12 から 10^-1 mol/L（段階6は 10^-18 から）、生成定数は数十桁にわたる。同じ組成で安定度の違う固相の組を含む。

## 制約

- 使えるのは Python 3 の標準ライブラリだけ（numpy、scipy などはない）。ネットワークはない。
- 1ファイルあたりの制限時間は 20 秒。
- `samples/` には段階1の入力と正しい出力がある。段階2以降の正解は与えられない。
