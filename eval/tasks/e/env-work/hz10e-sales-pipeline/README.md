# 売上集計パイプライン

`data/*.csv`（見出し `region,item,qty`）を読み、地域ごとの数量の合計と順位を出力する。

```
bash run.sh
```

## 出力

地域ごとに 1 行、順位の順に、タブ区切りで `<順位>\t<地域>\t<合計>`。

- 地域名は前後の空白を除いて小文字にしたもの。
- 順位は合計の大きい順に 1, 2, 3, …（同じ合計の地域が複数あるときは、地域名の昇順に並べ、順位も 1 ずつ進める）。
- 出力は、実行した時点の `data/*.csv` の内容だけで決まること。

## 中間ファイル

正規化した各 CSV を `build/norm/` に保存し、次回以降の実行で再利用する（大きなファイルの読み直しを避けるため）。

## 報告されている問題

- 同じデータなのに、CI で実行するたびに出力が変わることがある。
- データを直したのに、出力が古いままのことがある。
