# out/report.txt

## 営業日
- 営業日は現地時刻の 4:00 で切り替わる。0:00〜3:59 の売上は前日の営業日に数える。
- 月・年度は営業日で数える。年度は 4 月 1 日に始まる。

## 円への換算
- USD の金額は、その売上の営業日の月のレート（input/rates.csv）で円にし、円未満を四捨五入する（1 件ずつ）。

## 書式
支店名（branches.json のキーの文字列）の昇順（文字コード順。branches.json に書かれた並び順ではない）に、各支店の月を古い順に:

```
MONTHLY <支店> <YYYY-MM> <その月の売上合計（円）>
```

続けて MONTHLY と同じ支店の順に、データ全期間でその支店の売上合計が最も大きいカテゴリ（同額ならカテゴリ名の昇順〔文字コード順〕で先のもの）:

```
TOP <支店> <カテゴリ> <そのカテゴリの売上合計（円）>
```
