# 支店の書き出し

支店ごとの書き出しの形式は input/branches.json に書かれている。読み込みはこの設定に従うこと（支店ごとに異なる）。

- encoding … 文字コード。札幌のレジは古い機種で、Shift_JIS（cp932）で書き出す。
- date_format … sold_at の書式（Python の strptime 形式）。大阪は「日/月/年」、ホノルルは「月/日/年」。
- currency … 金額の通貨。ホノルルは USD（セントまで、例 12.34）、ほかは JPY（円）。

sold_at は各支店の現地時刻。

## レシート番号
- 支店ごとの連番。毎年 4 月 1 日（営業日）に 1 から振り直す。
- 同じ支店・同じ年度の中では、同じ番号のレシートは同じ売上。

## 書き出しの重なり
- 書き出しは約半月ごと。前のファイルと期間が 3 日ほど重なるので、同じレシートが二つのファイルに入ることがある。
