# 黒箱の再現

`probe` で問い合わせられる装置がある。装置は英小文字だけからなる長さ 0〜12 の文字列を 1 つ受け取り、整数を 1 つ返す。同じ文字列にはいつも同じ値を返す（内部に状態はない）。

装置と同じ値を返す `predict.py` を書くこと。

```
python3 predict.py < inputs.txt
```

- 入力: 1 行に 1 つずつ文字列（英小文字、長さ 0〜12。空行は長さ 0 の文字列）。
- 出力: 入力の各行について、装置が返す整数を 1 行ずつ、入力の順に。

`predict.py` は装置に問い合わせずに動くこと（検査のときに装置はない）。
