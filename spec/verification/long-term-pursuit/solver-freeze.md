# Solverのフリーズ記録

Astra Maxの独立評価「Solverの精度と改善余地の独立評価」で提示された3件の扱いを記録する。

| 提案 | 到達点 |
| --- | --- |
| 採点と終了条件を整合させる | 比較用採点器を修正し、値・単位・URL・出典の対応と、「不明」での完了・必須資料欠落での部分終了を別々に検証した。旧結果は保持した。 [検証情報の再比較](solver-feedback-regrade-comparison.md) |
| 実際に表示した出典本文の範囲を渡す | 出典ID・保存版・返却範囲・表示範囲を本文と分け、固定応答と実モデルで検証した。 [範囲表示の単独比較](solver-excerpt-range-comparison.md) |
| 同じ推論上限の中で終了判断と最終検証の枠を予約する | 未実装・未比較。固定応答の残枠境界と実モデルの効果検証が残る。 |

検証情報の引き継ぎは既定にする。単独比較では正しい完了16/16、適切な部分終了8/8を維持し、Outputは18.7%減った。範囲表示は `openExample({ ..., sourceRanges: true })` を指定した実行で使える。両機能の併用比較では24組で成果物の劣化は0件、再読・検索は15回から11回に減ったが、Input・Cached・Outputが増えたため併用の既定採用は見送った。 [併用比較](solver-combined-feedback-comparison.md)

この時点でSolverの改善をいったん凍結する。別モデルで効率化を検討できる段階になったら、同じ品質条件で再比較する。初回不合格からの回復を測った既存の実モデル比較に加え、白紙からの比較と終了枠の検証は今後の候補。比較の原ログと実行スナップショットは既存の運用どおりローカルの `artifacts/` に置く。
