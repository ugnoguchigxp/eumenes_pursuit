# Solverの検証情報と出典範囲表示の併用比較

2026-11-11 · [検証情報のみの比較](solver-feedback-regrade-comparison.md) · [出典範囲表示のみの比較](solver-excerpt-range-comparison.md)

## 条件

未使用の合成12課題を各2回、2方式で計48枠。全件確認で完了、「不明」を明記して完了、必須資料が欠けて部分終了の各4課題。比較は初回不合格からの回復を対象とし、資料取得、初稿の保存と読戻し、初回の受入検証は固定手順で揃えた。初稿には値・単位・出典の誤り、採点に必要な本文の不足、完了状態の誤りを含めた。4課題では、正答行がツール返却に含まれるものの、Solverが最初に見る範囲から外れるようにした。4課題のうち2題は最新観測、2題は古い観測として表示した。 [事前手順](../../../artifacts/solver-combined-feedback-20261111/protocol.md)

併用方式は、検証した版・判定理由・実際に使用した根拠、および保存本文の出典ID・版・表示範囲を含む現行の判断入力を使った。対照からは両機能の構造化情報と専用の説明を外し、出典本文を旧表示に戻した。通常の判定理由、採点器、資料、ツール、モデル `gpt-6-luna / medium`、上限（モデル17回、子ツール6回、検索0回、420秒）と予算を共通にした。方式の実行順はペアごとに交互で、最大8組を並行実行した。 [実行コード](../../../artifacts/solver-combined-feedback-20261111/run.ts) · [共通採点器](../../../eval/solver-comparison/grader.ts) · [固定したファイルの識別子](../../../artifacts/solver-combined-feedback-20261111/frozen.sha256)

採点では値・単位・公式URL・出典IDと根拠本文の対応、未確認項目と限界、要求に沿った終了を照合し、公開Markdownが採点した版と一致することを求めた。手戻りは比較開始以降で数え、再読・検索には保存済み出典への `source_read` と `source_find` を含めた。InputはAPIの入力総数、Cachedはその内数、Outputは出力総数。固定準備と機械採点は使用量の集計から除いた。

部分テスト19件と結合テスト4件が通過した。固定応答の通しでは全24枠が期待した終了となり、12組で開始状態の一致を確認した。過去の比較と課題ID・資料URLの重複はなかった。 [部分](../../../artifacts/solver-combined-feedback-20261111/unit.log) · [結合](../../../artifacts/solver-combined-feedback-20261111/integration.log) · [固定応答の通し](../../../artifacts/solver-combined-feedback-20261111/preflight.log) · [開始状態の照合](../../../artifacts/solver-combined-feedback-20261111/preflight-audit.log)

## 採否

**両機能を併用する方式の既定採用は見送る。** 成果物の品質は同等で、保存済み本文の再読・検索は4回減った。モデル要求数は同じで、全体のInput・Cached・Outputはいずれも増えた。とくにOutputは3,095トークン増えた。この判断の対象は今回比較した併用方式。

試験は固定資料を使った初回不合格からの回復を対象とした。各機能の寄与や、白紙からの実行での効果はこの試験では測っていない。
