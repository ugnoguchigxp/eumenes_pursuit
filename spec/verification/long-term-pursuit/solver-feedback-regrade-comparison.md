# 修正済み採点器によるSolverの再比較

2026-11-11 · [実装計画](../../solver-verification-feedback-plan.md) · [前回の比較と採点上の制約](solver-feedback-live-comparison.md)

## 比較条件

未使用の合成12課題を各2回、2方式で計48枠。全件確認で完了、不明を明記して完了、必須資料が欠けて部分終了の3群に各4課題を割り当てた。全件確認・不明許容の両群には、採点用の抜粋不足と報告の値の誤りを各2課題含めた。取得不能の資料は固定応答で取得失敗を返す。

資料取得、初版の保存・読戻し、最初の受入検証の不合格までは共通の固定手順。その後は両方式とも `gpt-6-luna / medium` で判断する。対照の判断入力から `criterion.verification` だけを除き、自由記述の理由、合否、道具、指示は共通とした。値・単位・URL・出典を照合する修正済み採点器を双方で使い、公開Markdownが照合対象と一致することも確認した。 [共通採点器](../../../eval/solver-comparison/grader.ts)

方式の順はペアごとに交互とし、各ペア内は直列、最大8組を並行で実行した。共通上限は1枠420秒、ホスト推論17回、外部操作6回、検索0回。事前の固定応答では24枠すべてが期待した終端に達し、12組すべてで初回検証時点の状態が一致した。 [事前手順](../../../artifacts/solver-feedback-regrade-20261111/protocol.md) · [固定応答のログ](../../../artifacts/solver-feedback-regrade-20261111/preflight-frozen.log) · [実行条件](../../../artifacts/solver-feedback-regrade-20261111/live/manifest.json)

正しい完了は、独立照合に合格し、公開Markdownが照合対象と一致して完了した件数。部分終了は、必要な資料が欠けた状態で、明示的な部分終了の判断が採用され、確認済みの値と出典、未確認事項、限界が保存・読戻しされた件数。再取得、ローカル本文の再読・検索、再保存は最初の不合格以降に数え、再保存には本文の修正を含む。Inputは入力総数、Cachedはそのうちキャッシュから読み出した分、Outputは出力総数。固定応答と機械採点は使用量の集計から除いた。

## 採否

**検証情報を次の判断に渡す方式を採用する。** 全48枠で公開Markdownが採点対象の回答案と一致した。24組の対比較で、値・単位・URL・出典および終了条件の採点上、成果物が劣化した組は0件だった。両方式とも正しい完了16/16、適切な部分終了8/8、誤完了0件。検証情報ありではOutputが18.7%、Inputが7.2%、Cachedが13.7%減り、保存済み本文の再読・検索は15回から12回に減った。

当初はInputとOutputの両方に10%以上の削減を求めた事前基準に従い、Inputが届かなかったため見送った。今回の採用判断では成果物の品質とOutputの削減を重視した。「不明」で完了できる課題群ではOutputが17,276から19,546に増えたため、全体の削減率は課題構成に依存する。

この比較は固定資料を使った初回不合格からの回復を対象とした。修正前の比較とは採点契約と課題が異なる。後続の[出典表示範囲の比較](solver-excerpt-range-comparison.md)では双方から検証情報を外しており、両変更を併用した場合の効果は [併用比較](solver-combined-feedback-comparison.md) に記録した。採否の見直しはこの報告に記録した。 [実行コード](../../../artifacts/solver-feedback-regrade-20261111/run.ts) · [固定したファイルの識別子](../../../artifacts/solver-feedback-regrade-20261111/frozen.sha256)
